## 🔍 官方客服与营销号客观事实核验

1. **主体矩阵界定（蓝V认证 vs 渠道营销号）**：
   * 唯一官方客服：仅企业蓝V认证账号 **「美的官方客服」** 具备品牌官方售后职能，共留言 **71 次**；
   * 渠道营销号：其余如「COLMO佛山体验馆」、「京东电器推荐官」、「自营直播间」等跟帖均为**分销带货获客号**，不具备官方售后介入能力；
   * 竞品截流：竞品账号 **「海尔智家客服」** 在客诉帖下方跟帖 2 次，主动推介以旧换新。
2. **触发规则**：
   * 标题含“生锈/漏水/维权/避坑/千万别买”的高危帖，蓝V客服介入率达 **50.0%**，多在 12 至 36 小时内现身；
   * 常规日常安装或咨询贴，蓝V客服留言率仅为 **19.0%**。
3. **话术模式**：
   * 100% 格式化套话（表达歉意 + 索要联系电话和具体地址），公域零事实答疑与技术解释。
4. **闭环状态**：
   * 65 篇蓝V留痕笔记的公开评论区中，**未见官方客服后续发表任何公域结案或回访说明**；
   * 用户反弹集中在：私信后长时间无回复、线下网点归咎于水质拒不换机、服务站私自虚假结单。

## 🖥 交互式报告特色

本项目提供完全单文件化的极简交互报告 `index.html`：
* **严格区分身份**：筛选器与数据表格明确区分「美的官方客服 (蓝V)」与「仅营销/渠道号」；
* **极简无边框设计**：纯白描纪实风格，所有标签均去除描边线框，搭配精细圆弧矢量图标（Stroke 1.5 SVG）；
* **评论树下钻**：点击任意笔记行末的“查看”，即可在浮层中调阅该笔记的全部主评、二级追评树及官方客服留言留痕。
