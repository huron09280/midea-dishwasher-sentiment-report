# 美的洗碗机 · 小红书公开笔记与客服沟通实录 (2026.06 - 2026.09)

> **数据周期**：2026年6月1日 - 2026年9月9日（覆盖 618 大促选购交付、7月试用磨合、8月集中反馈至9月秋季装修季）  
> **数据采集**：通过 \`huashu-chrome\` 真实浏览器会话，对小红书平台“美的洗碗机”相关公开笔记与评论区进行穿透采集与白描实录。

---

## 📊 核心数据概览

* **采得笔记总量**：**215 篇**（跨 6 大检索向量精准去重）
* **穿透分析评论**：**2,221 条**（包含 1,342 条一级主评 + 879 条二级追评）
* **质量与售后反馈**：**75 篇**（占比 34.9%）
* **官方专人跟帖笔记**：**75 篇**（整体介入率 34.9%，高危避坑/生锈/漏水帖介入率高达 **75.3%**）
* **用户公域针对性追问**：**26 条**（针对官方客服模板化留言发表直接反问与事实驳斥）

---

## 🔍 官方专人处理客观事实核验

1. **主体矩阵**：
   * 企业蓝V认证账号 **「美的官方客服」** 为核心介入方（共留言 73 次，占比 76.8%）；
   * 竞品账号 **「海尔智家客服」** 在客诉帖下方潜伏跟帖 2 次，主动推介以旧换新。
2. **触发规则**：
   * 标题含“生锈/漏水/维权/避坑/千万别买”的高危帖介入率达 **75.3%**，多在 12 至 36 小时内现身；
   * 常规日常安装或咨询贴介入率仅 **27.1%**。
3. **话术模式**：
   * 100% 格式化套话（表达歉意 + 索要联系电话和具体地址），公域零事实答疑与技术解释。
4. **闭环状态**：
   * 75 篇留痕笔记的公开评论区中，**未见官方客服后续发表任何公域结案或回访说明**；
   * 用户反弹集中在：私信后长时间无回复、线下网点归咎于水质拒不换机、服务站私自虚假结单。

## 🖥 交互式报告预览

本项目提供完全单文件化的极简交互报告 \`index.html\`：
* **多维筛选**：支持按月份（6/7/8/9月）、客诉分类、客服介入状态联动筛选；
* **评论树下钻**：点击任意笔记行末的“查看”，即可在浮层中调阅该笔记的全部主评、二级追评树及官方客服留言留痕；
* **极简无边框设计**：纯白描纪实风格，搭配精细圆弧矢量图标（Stroke 1.5 SVG）。
